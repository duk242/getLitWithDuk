## EOS Sneak a manual light as a cue
This is useful if you're manually driving a moving light as a follow spot. The followspot has finished and you want to sneak the light back to the position it should be in ready for the next followspot.

**Create the Macro**  
`[Learn][Macro]_MacroNumber_[Enter]` Put it into Macro Learning Mode with the Macro Number you've set.  
`_ChannelNumber_[Sneak][Enter][Learn]` Select the Channel, Sneak, Enter then Learn to turn of Macro Learn Mode

**Link the Macro to the cue**  
`[Cue]_CueNumber_{Execute}{Macro (Soft Key)}_Macro Num_[Enter]`   Select the Cue -> Execute Soft Key -> Macro SoftKey -> Macro Number then Enter to save.
