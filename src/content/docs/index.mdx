## Welcome
Welcome to Gettin Lit With Duk! 
This project is a culmination of all the things I've learned with lighting, some of the content is links off to other websites or books/videos that I've found useful, other parts I've written myself.

## Sections of the Website 
### Lighting Design
This is working out how you want things to look as well as the when you want things to look that way.
It involves:
* Colour Theory
* Where you can put lights and lighting angles
* Creating Lighting Diagrams
* Using a script to add lighting notes

### Lighting Programming
This is about using the Lighting Desk to program your lighting cues

### Light Profiles
It's like character sheets, but for all the different lights I use!
It's a handy reference guide for what the lights are capable of, as well as useful information about power usage/weight etc without having to look up the manual for each light (the manual is in there too though!)

### Light Recipes
Lighting Scenes I've done along with a brief description of how it was achieved. This is partially a portfolio of my own work, but also notes and hints about how you can achieve the look yourself.

### Venue Specific information
This is really only useful to people working in the Coffs Harbour area, it's just a collection of the tech specs and available lighting at each venue that I usually work in.
