## Overview
This is a general page for all sorts of WLED devices.

WLED is the software that runs on a small ESP32 chip and can be used to drive small LED lights or strips.

## Power Requirements
It has 2 wires for power input - you'll need a power supply that's rated for more (Aim for 20-30% more) than the LEDs you're using.

To calculate power requirements, use the [WLED Power Calculator Tool](https://wled-calculator.github.io/)
Eg. 3meters of WS2811 12V LEDs at 60 LEDs/Meter is 2.44A at full brightness.

## Networking and Wifi
By default, they create a little wifi network, SSID is WLED, password is wled1234
Connect to that, it should come up with a captive portal page, but if it doesn't go to a webbrowser and navigate to http://4.3.2.1
